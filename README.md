# 정부 지원사업 알리미

매일 아침 정부·지자체 지원사업 공고를 모아, 내 지역·업종에 맞는 것만 골라 보여 주고 텔레그램으로 알려 주는 Windows용 프로그램입니다.

- **전국 공통 8곳 + 우리 지역 기관**: 지역만 고르면 그 지역 테크노파크·진흥원이 붙습니다 (17개 시·도)
- **지역·업종 점수**: 안 맞는 공고는 점수가 깎여 빠집니다
- **내 컴퓨터 대시보드**: 기관·점수·마감일로 걸러 보고, 지난 공고도 다시 찾습니다. 누르면 그 공고 글로 이동합니다
- **텔레그램 알림 (선택)**: 20건 넘는 날은 요약 한 통, 0건인 날도 "오늘은 없었습니다" 한 통

파이썬 표준 라이브러리만 사용합니다 (인증서 확인용 `truststore` 제외). 데이터는 내 컴퓨터(`data/alimi.db`)에만 저장됩니다.

**웹 대시보드: <https://limwonsuk.github.io/gov-support-alimi/>** — GitHub Actions 가 매일 08:00(KST) 수집해 게시합니다.

## 빠른 시작

1. [Python](https://www.python.org/downloads/) 설치 ("Add python.exe to PATH" 체크)
2. `config.example.json` 을 `config.json` 으로 복사하고 `"내_지역"` 수정
3. `1_설치하기.bat` 실행 → `2_대시보드_열기.bat`

자세한 설치·텔레그램 연결·기관 추가·수리법은 **[설치설명서.md](설치설명서.md)** 를 보세요.
